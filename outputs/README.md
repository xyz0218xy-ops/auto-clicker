# 自动点击器 v31 使用说明

## 交付内容

| 文件 | 说明 |
|------|------|
| `dist/AutoClicker.exe` | 单文件程序，双击即可运行，目标电脑无需安装 Python |
| `dist/click_positions.json` | 全部方案数据（采集点、热键、随机倍率），程序自动读写 |
| `auto_clicker.py` | 源码（Python 3.8 + tkinter，约 1330 行） |
| `build_exe.ps1` | 一键打包脚本（已含 Tcl/Tk 与 Tesseract OCR 运行依赖） |

## 本次落实的需求

### 1. 采集的数据关机后不再丢失

旧版把配置写到 PyInstaller 的临时解包目录，程序一退出文件就被删掉，所以每次都要重新采集。

现在的做法：

- 配置文件固定保存在**程序所在目录**：`click_positions.json`
- 写入采用「先写临时文件 → 再原子替换」，并自动保留一份 `click_positions.json.bak`
- 主文件损坏时自动读取备份
- 启动时、每次修改后 0.5 秒、关闭程序时都会保存
- 程序文件夹不可写时（例如放在 `Program Files`），自动改用 `%APPDATA%\AutoClicker`

### 2. 按住左键 → 按住右键

按住右键有三种控制方式，互相不冲突：

| 方式 | 怎么用 |
|------|--------|
| 按钮 | 点「按住右键」，按钮变成「松开右键」，再点一次松开 |
| 独立热键 | 默认 **F8**，随时按随时开 / 关，**不需要程序处于运行状态** |
| 随运行同步 | 勾选「运行开始时同步按住右键」，按 F12 开始点击时自动按住，停止时自动松开 |

- 按住期间后台线程每 50 毫秒重复发送一次右键按下信号，游戏才认得住
- 再按一次、或关闭程序时自动松开，不会卡住鼠标
- 手动按住的（点按钮或按热键）不会被「停止」误松开；只有随运行自动按住的那次才跟着停止一起松开
- 启停热键和按住右键热键不能设成同一个键，设置时会提示换一个
- 按住右键热键、同步开关都按方案独立保存

### 2. Boss 卡 OCR 计数模式

- 按星级采集 Boss 卡数量区域、星级卡片坐标和召唤按钮坐标
- 启动时读取初始数量，每次确认数量从 N 降到 N-1 后才计数一次
- 达到设定召唤次数后自动停止，进度会随方案保存
- 自由循环模式仍然保留，两种模式可以按方案选择
### 4. 换电脑也能直接用

- 打包为**单文件 exe**，任何 Windows 电脑双击就能跑，不需要装 Python 或任何库
- 代码里不写死盘符或用户名，所有路径都相对程序自身
- 首次运行时，程序会在自己旁边生成 `runtime` 文件夹（Tcl/Tk 界面运行库，约 4 MB），之后不再重复解包
- 程序所在文件夹不可写时，运行库自动释放到 `%LOCALAPPDATA%\AutoClicker`
- 附带 `--selftest` 自检：`自动点击器.exe --selftest` 会在程序目录生成 `selftest.txt`，记录数据文件位置、方案数量、键盘库、权限、运行库等状态

> 迁移方式：把 `自动点击器.exe` 和 `click_positions.json` 一起复制到新电脑的同一个文件夹，方案数据原样可用。

### 5. 间隔随机化（防固定节奏）

- 界面新增「间隔随机化」开关与倍率区间，默认 **0.5 ~ 2.0 倍**，默认开启
- 例：某项间隔设为 `0.1` 秒，实际等待会在 **0.05 ~ 0.2 秒**之间随机取值
- 每次执行都重新随机，不会出现固定节奏
- 倍率区间可以自己改，例如 `0.8 ~ 1.3` 表示小幅抖动
- 设置按方案独立保存

> 第 3 条「界面重做」按要求未做。

## 相对偏移

不想为挨着的第二个位置再采集一次时，可以让某个点自动「跟在」上一个点旁边：

- 双击列表某一行 → 位置选「相对上一个鼠标点」→ 填偏移像素（范围 ±2000）
- 列表里直接显示换算结果，例如 `偏移 +120,-40 → (951, 520)`，一眼能看出最终点到哪
- 偏移相对**上一个鼠标点击**计算，中间的按键项不影响累加
- 基准点变了（换分辨率、窗口挪了位置），偏移点会自动跟着走

> 如果相对点前面没有鼠标点击（比如排在第一位），列表会提示「前面没有参照点」，这时按绝对坐标处理。

## 轮次间隔

列表跑完最后一项算一轮，可以设置每轮之间等多久再开始下一轮：

- 在「热键与间隔」区填「轮次间隔」，支持 `3`、`30s`、`1h30m` 这类写法
- 填 `0` 表示不停顿，一轮接一轮
- 轮次间隔同样走随机化倍率

## 数据导入 / 导出

主界面顶部方案栏右侧有「导入」「导出」两个按钮，用于把别处保存的方案搬进来或备份出去。

### 导入

点「导入」→ 选择一份 `click_positions.json`（旧程序导出的、或别的电脑上备份的），按以下规则合并：

| 情况 | 处理 |
|------|------|
| 本地没有同名方案 | 直接新增 |
| 本地有同名方案，但列表是空的 | 用导入文件里的内容覆盖 |
| 本地有同名方案，且已有采集数据 | 保留本地，不覆盖 |

导入结束后会弹窗列出「新增 / 覆盖 / 保留」各是哪些方案；如果导入文件里某些方案本身没有采集点，也会单独提示。

### 导出

点「导出」→ 选择保存位置，会把当前全部方案写成一个 json 文件，方便备份或拷到别的电脑。

### 旧格式兼容

导入时会自动识别早期版本的文件格式，不用手动改：

- 位置列表字段叫 `positions` 还是 `items` 都能读
- 按键名支持 `↓` / `Down` / `↑` / `Right` 这类写法，以及 `123` 这种键码数字（会转成 `f12`）和常见中文键名
- 旧条目没有 `type` 字段时，按是否带按键来自动判断是「按键」还是「鼠标点击」

## 基本用法

1. 双击 `自动点击器.exe`
2. 点击「采集点击」→ 3 秒倒计时内把鼠标移到目标位置 → 倒计时结束自动记录坐标
3. 需要按键就点「采集按键」→ 按下要绑定的键
4. 想直接填坐标就点「手动添加」，可填 X / Y 或绑定按键，并设定间隔
5. 双击列表任意一行可以修改名称、坐标/按键、间隔
6. 输入间隔后按 `F12`（或点「▶ 开始」）开始循环执行，再按 `F12` 停止

### 间隔怎么写

- 单位：秒（默认）、分、时，范围 **0.05 秒 ~ 2 小时**
- 支持写法：`2h`、`30m`、`90s`、`1h30m`、`1.5h`、`1分30秒`、`7200`

### 方案管理

- 「新建」= 全新空白方案；「复制」= 当前方案的独立副本
- 各方案的位置列表、热键、随机倍率互不影响，删除一个方案不会影响其他方案
- 旧版 `click_positions.json` 会自动迁移，不会丢数据

### 热键

- 默认 `F12`，点「设置热键」后按任意键即可改绑
- 用 Windows 低级键盘钩子实现（`keyboard` 库），游戏全屏时也能触发

## 使用须知

- **建议以管理员身份运行**：程序右下角有「以管理员身份重启」按钮。注入输入需要权限，尤其是游戏以管理员启动时。
- 目标程序若为**全屏独占**模式，鼠标只能落在游戏里；切到「无边框窗口」或「窗口化」更稳。
- 关于反作弊：主流游戏（如穿越火线 ACE）会校验输入来源是否为真实硬件设备。软件层模拟（`mouse_event` / `keybd_event` / `SendInput` / `PostMessage`）都可能被识别并拦截，这不是代码写法能绕过的，属于内核级限制。
- 使用前请确认符合目标软件的用户协议。

## 故障排查

| 现象 | 处理 |
|------|------|
| 双击没反应 | 运行 `自动点击器.exe --selftest`，查看同目录 `selftest.txt` |
| 提示缺 `tcl` / `init.tcl` | 删除程序旁边的 `runtime` 文件夹后重新运行，让它重新解包 |
| 键盘功能不可用 | 自检里看「键盘库 keyboard」是否为可用；被杀毒软件拦截时加白名单 |
| 点击无效 | 换「以管理员身份重启」；把游戏切成窗口化；确认采集的坐标准确 |
| 按住右键热键没反应 | 确认没被别的软件占用同一个键；点「设置热键」重设一次；以管理员身份重启程序 |
| 相对偏移点跑到别处了 | 看列表「内容」列显示的换算坐标；确认偏移量没超过 ±2000 |
| 换电脑后方案不见了 | 把 `click_positions.json` 和 exe 放在同一个文件夹 |
